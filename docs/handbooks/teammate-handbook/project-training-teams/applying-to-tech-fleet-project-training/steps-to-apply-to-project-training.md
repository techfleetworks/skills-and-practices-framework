# Steps to Apply to Project Training

* [Join Discord](/resources/quick-links/join-tech-fleet-discord.md)
* [Read about how Tech Fleet project training is defined](/team-portal/new-teammate-handbook/expectations-for-teammates/training-versus-volunteering.md) to make sure you understand how to put it on your resume
* Prepare for Tech Fleet project training by:
  1. [Engage within the community](/resources/quick-links/join-tech-fleet-discord.md)
  2. [Read the Agile Handbook ](/agile-training-portal/agile-handbook.md)
  3. [Read the Project Success Handbook](/project-portal/project-success-handbook.md)
  4. [Read the Teammate Handbook](/team-portal/new-teammate-handbook.md)
  5. [Observe projects](/observer-portal/observer-handbook.md)
  6. [Train in Agile](/agile-training-portal/agile-training-in-tech-fleet.md)
* [Check out the Current Openings](/training-openings/current-and-upcoming-program-openings/project-training-openings.md)
* Fill out the [General Application and the Project Phase Application](/training-openings/application-forms.md)
* [Update your General Application answers](/team-portal/new-teammate-handbook/project-training-teams/applying-to-tech-fleet-project-training/updating-the-general-application.md) as you need.
* Proceed with the application process as described [here](/team-portal/new-teammate-handbook/project-training-teams/applying-to-tech-fleet-project-training/project-timelines-and-application-process.md)
