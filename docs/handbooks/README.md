# Handbooks

Long-form Tech Fleet handbooks, pulled from GitBook (guide.techfleet.org) as Markdown.
They are the narrative companion to the structured data in `data/`: the data says *what*
the pieces are, the handbooks teach *how* the work is done.

- **Agile Handbook** — `agile-handbook/` (56 pages)
- **New Teammate Handbook** — `teammate-handbook/` (72 pages)
- **Project Success Handbook** — `project-success-handbook/` (40 pages)

> Source of truth for the prose is GitBook; this is a synced snapshot. Regenerate with `node tools/extract-handbooks.mjs`.
