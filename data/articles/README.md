# Articles

Long-form Tech Fleet articles that explain the Skills & Practices Framework and Team Practices in
narrative form. They are the "why" companion to the structured data in `data/json/` and the
handbooks in `data/handbooks/`: the data says *what* the pieces are, the articles explain the
*vision and reasoning* behind them.

Each file's first line is a blockquote carrying the article's canonical public URL (Medium) and the
CC BY 4.0 license. Consumers (e.g. the Fleety chatbot) ingest the Markdown as retrievable content and
use the canonical URL as the citation link.

- **Practices: the Invisible Components That Drive Empowered Teamwork** — `team-practices-introduction.md`
- **A Comprehensive Tech Skills Information Architecture for New Grads and Career Changers** — `skills-and-practices-framework-introduction.md`
- **How Might We Make Tech Fleet Talent More Marketable** — `spf-vision-statement.md`
