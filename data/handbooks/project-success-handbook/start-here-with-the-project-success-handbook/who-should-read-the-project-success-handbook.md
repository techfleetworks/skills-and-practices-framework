# Who Should Read The Project Success Handbook?

## Who Should Read This Handbook?

Everyone should read this handbook! If you are trying to form teams to do work together, this handbook is for you. It provides important details about cross-functional teamwork, project operations, and expectations.&#x20;

## Audiences of the Handbook

1. Apprenticeship teammates
2. Volunteers
3. Leadership
4. Guild members
5. Project coordinators
6. Agile coaches
