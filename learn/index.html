The big idea

The framework is a shared language for how people work well together. Instead of one long list, it breaks the work into a set of connected data types — skills, practices, deliverables, milestones, roles, and more. Each type is defined clearly, and every type relates to the others.

That web is the point. A deliverable is made through activities, which call for skills, shaped by practices, owned by a duty, and marking a milestone in a project. Learn the pieces and how they link, and you can see the whole shape of the work. Below, meet each type and click any connection to see it explained.
