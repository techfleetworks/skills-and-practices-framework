# API

This folder holds the browsable documentation for the framework's data.

## What it is

The framework is published as plain JSON files (a "static API"): every dataset is a file
served by GitHub Pages, so it is free, fast, and always available. There is no server to run
and nothing to log in to.

- **`../openapi/openapi.json`** — the OpenAPI 3.1 description of every dataset endpoint. This
  is the standard, machine-readable contract; tools like Postman, code generators, and AI
  agents can read it directly. It is generated by `tools/build-openapi.mjs` from the manifest,
  so it always matches the data.
- **`index.html`** — a documentation website rendered by [Scalar](https://scalar.com) (free and
  open source). It reads the OpenAPI file and lets anyone browse the datasets and run a live
  "Try it" against the real files.

## Viewing it

Once GitHub Pages is enabled for this repository (Settings → Pages → Deploy from branch →
`main` / root), the docs are live at:

```
https://techfleetworks.github.io/skills-and-practices-framework/api/
```

To preview locally, serve the repository root with any static server and open `/api/`:

```bash
npx serve .
```

## How it serves the five use cases

- **Fork it** — the OpenAPI file and JSON Schemas describe the whole shape, so a fork knows
  exactly what it is getting.
- **Chatbots and professional-development answers** — an AI agent can read `openapi.json`, then
  fetch the datasets it names, with the schema.org / SKOS mapping in `schema/context.jsonld`.
- **Narrative and relationship tools** (career coaching, curriculum guidance, project-team
  advice) — the endpoints expose the relationships between skills, practices, roles, and
  company types that these tools reason over.
- **Contributing new data** — the schemas and the validator define what a valid contribution
  looks like.
- **Apps, LLMs, and companies building on it** — a stable, documented, standards-based contract
  they can depend on.
